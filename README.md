# Forme Studio

A responsive React storefront concept for customizable printed T-shirts and hoodies. Product data and cart state are local; checkout is a demo and does not process payments.

## Run locally

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Features

- Responsive storefront and product category filters
- Product customization for color, size, placement, text, and artwork upload
- Local shopping bag with quantity controls
- Mock product catalog and demo checkout
